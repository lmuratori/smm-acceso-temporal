11. EL MOTOR: Codigo.gs (backend en Google Apps Script)
--------------------------------------------------------------------

Este archivo NO se sube a GitHub. GitHub solo sirve las paginas que
ves (el "frente" del sistema). Codigo.gs es el "motor" que procesa
todo por detras: guarda datos, manda mails, genera links de Meet,
lee fotos con inteligencia artificial, etc.

Vive en un proyecto de Google Apps Script llamado "S.M.I-M", ligado
a un archivo de Google Drive de la cuenta:

    consultas.sism@gmail.com

Para actualizarlo cuando haya cambios:
  1. Entrar a script.google.com CON LA CUENTA consultas.sism@gmail.com
  2. Abrir el proyecto "S.M.I-M"
  3. Reemplazar todo el contenido del archivo Codigo.gs por el que
     esta en la carpeta backend/ de este paquete
  4. Guardar (icono de disquete o Ctrl+S)
  5. Implementar (boton azul arriba a la derecha) -> Administrar
     implementaciones -> lapiz de editar en la implementacion activa
     -> cambiar Version a "Nueva version" -> Implementar

La direccion (URL) de la Aplicacion Web NO cambia nunca con este
paso, asi que ningun archivo HTML necesita tocarse despues.

Novedad incluida en esta version 1.0: nueva funcion
analizarFotoHistoria(), que es la que usa Lector_Historias.html para
leer fichas por foto.

13. COMO SUBIR ACTUALIZACIONES FUTURAS A GITHUB
--------------------------------------------------------------------

Recomendado: usar GitHub Desktop (programa gratuito, sin lineas de
comando), ya instalado y configurado en tu PC.

  1. Abrir GitHub Desktop
  2. Arriba a la izquierda, confirmar que el "Current repository"
     sea smm-acceso-temporal
  3. Boton "Show in Explorer" para abrir la carpeta del repositorio
     en tu PC
  4. Copiar y pegar ahi los archivos nuevos/actualizados,
     reemplazando a los viejos cuando Windows lo pregunte
  5. Volver a GitHub Desktop: los archivos cambiados van a aparecer
     solos en la lista de la izquierda
  6. Escribir un breve resumen en el cuadro "Summary" (por ejemplo:
     "Actualizacion vademecum ANMAT")
  7. Boton "Commit to main"
  8. Boton "Push origin" (arriba, aparece despues del commit) para
     subirlo de verdad a GitHub

El sitio en vivo (GitHub Pages) se actualiza solo, entre 30 segundos
y un par de minutos despues del Push. Puede hacer falta refrescar
fuerte el navegador (Ctrl+F5 en PC) para ver el cambio.
